# Contributing to AURA

## Workflow

1. Create a short-lived branch such as `feature/task-service` or `bugfix/task-timeout`.
2. Keep the change within the current roadmap phase.
3. Run the relevant backend and frontend checks documented in the README.
4. Open a pull request using the repository template.
5. Address review feedback before merging.

Use Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, or `chore:`.

Never commit `.env`, API keys, tokens, or production credentials. Add documented placeholders to `.env.example` when configuration changes.
